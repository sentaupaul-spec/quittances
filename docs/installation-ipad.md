# Checklist d'installation sur l'iPad d'Annie

À faire une fois, sur place (ou en la guidant au téléphone). Compter 15 minutes.

**Avant de partir :** le Sheet est partagé et le lien `https://sentaupaul-spec.github.io/quittances/` fonctionne
sur ton ordinateur (la liste des locataires s'affiche). Imprime [`notice-annie.pdf`](notice-annie.pdf).

## Sur l'iPad

- [ ] **Version d'iPadOS** : Réglages › Général › Informations › « Version d'iPadOS ». Il faut **15 ou plus**
      (le menu Partager avec pièce jointe n'existe pas avant). Sinon : Réglages › Général › Mise à jour logicielle.
- [ ] **Compte d'envoi** : ajouter `locationslogements34@gmail.com` dans Réglages › Apps › Mail › Comptes
      (sur les versions plus anciennes : Réglages › Mail › Comptes), puis le choisir dans **Compte par défaut**
      (tout en bas de la page Mail). L'app ne peut pas choisir l'expéditeur : c'est ce réglage qui décide.
- [ ] **Mail fonctionne** : ouvrir l'app Mail, s'envoyer un mail et vérifier que « De : » affiche bien cette adresse.
- [ ] **Supprimer l'ancien raccourci mort** : appui long sur l'ancienne icône › « Supprimer le signet »
      (ou « Supprimer l'app » › « Supprimer de l'écran d'accueil »).
- [ ] **Ouvrir le nouveau lien dans Safari** : taper `https://sentaupaul-spec.github.io/quittances/`.
- [ ] **Ajouter à l'écran d'accueil** : bouton Partager (carré avec une flèche vers le haut, en haut à droite)
      › « Sur l'écran d'accueil » › vérifier le nom **Quittances** › « Ajouter ».
      (Si proposé : laisser « Ouvrir comme app web » activé.)
- [ ] **Fermer Safari**, puis ouvrir l'app **depuis l'icône**. Vérifier :
  - « Liste mise à jour le … » en haut, et les locataires groupés par logement ;
  - « Version 1.4.0 » (ou plus) tout en bas.
- [ ] **Placer l'icône** sur le premier écran, bien visible (dans le Dock si possible).

## Tests

- [ ] **Test d'envoi** : choisir un locataire › « Envoyer par mail » › Mail › toucher « À : » puis « Coller » (l'adresse copiée doit apparaître)
      › remplacer par **ton** adresse pour ce test › vérifier « De : » › envoyer. Sur ton ordinateur : la pièce jointe s'appelle `Quittance_<Mois>_<Année>_<Nom>.pdf`,
      1 page, signature et tampon visibles, montant en lettres correct.
- [ ] Le texte du mail est bien pré-rempli (« Bonjour Prénom Nom, Voici votre quittance… »).
- [ ] **Télécharger le PDF** : le fichier arrive dans l'app Fichiers › Téléchargements.
- [ ] **Hors ligne** : activer le mode Avion › rouvrir l'app › « Pas de connexion internet : liste du … »
      s'affiche et on peut quand même télécharger une quittance. **Désactiver le mode Avion.**
- [ ] Faire faire **une quittance complète par Annie elle-même**, avec la notice, sans l'aider.

## Pour finir

- [ ] Poser la notice imprimée près de l'iPad, avec **ton numéro de téléphone** écrit à la main.
- [ ] Lui dire : « Toujours l'icône Quittances, jamais Safari. »
